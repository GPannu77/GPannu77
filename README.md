### Telco Customer Churn Analysis

An end-to-end SQL analytics project that cleans a telecom customer dataset, uncovers what drives churn, and presents the findings in a Power BI dashboard.

| Category         | Details                                                                                                           |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Stack**        | MySQL · SQL · Power BI                                                                                            |
| **Dataset**      | 7,032 telecom customers                                                                                           |
| **Key Findings** | 631-customer high-risk segment with a 71% churn rate · 30.5% of monthly revenue lost to churn                     |
| **Impact**       | Demonstrates SQL data cleaning, advanced analytical queries, risk scoring, and business-focused dashboarding       |
| **Repository**   | [GitHub Profile](https://github.com/GPannu77)                                                                     |

### Engineering Scope

* Cleaned and standardized the dataset in MySQL, adding churn flag and tenure group fields for analysis
* Analyzed churn by contract type, internet service, payment method, and tenure using CTEs, window functions, and subqueries
* Identified a high-risk segment of 631 customers with a 71% churn rate
* Built a 0–5 risk score that separates customers from 2.5% to 72% churn
* Built a Power BI dashboard from a SQL view showing churn drivers and revenue lost to churn (30.5% of monthly revenue)

</details>
